# Collection copy takes name, category, and tax code; price and stock start at 0

Include all products copies each source product's name, category, and tax code id into the new collection. Wholesale price, retail price, stock in hand, and total stock on each copy are 0. The source collection's products are not updated.

The rejected alternative was copying wholesale price, retail price, stock in hand, and total stock as well. That would carry last year's prices and counted metres into a new collection when the operator only wanted the catalogue and tax codes.
