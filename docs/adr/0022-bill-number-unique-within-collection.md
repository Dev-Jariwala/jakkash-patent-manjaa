# Bill number unique within collection

Status: accepted

Supersedes [0018-manual-shop-wide-bill-number.md](./0018-manual-shop-wide-bill-number.md).

A bill number is unique within the collection the Bill was raised in. A number used only on a Bill in another collection is allowed. A second copy in the same collection is still rejected with "This bill number is already in use."

The hand-typed number and the rule that Edit may change it are replaced by [0029-bill-series-year-and-serial.md](./0029-bill-series-year-and-serial.md).

The rejected alternative was keeping the number unique across the shop, which blocked reusing the same series in each collection.
